# 歡樂抽獎系統 V1.1.0 正式版

## 啟動
1. 解壓縮 ZIP。
2. 在資料夾開啟終端機／黑色視窗。
3. 第一次執行：`npm install`
4. 啟動：`npm start`
5. 主控登入：`http://localhost:3000/admin-login.html`

本機測試主控密碼：`8888`
Render 上架時可用環境變數 `ADMIN_PASSWORD` 改成自己的密碼。

## 正式版功能
- 玩法：戳氣球、砸金蛋。
- 氣球：一般、愛心、星星、花朵、雲朵、彩虹；整盤只用一種造型，可開／關飄動。
- 金蛋：彩色 Q 版蛋、Q 版亮晶晶金蛋。
- 主控自填總格數，最高 500 格；手機版大量格數自然換行、上下滑動。
- 主控只輸入真正有獎的獎品名稱與數量。
- `總格數 - 有獎數量 = 系統自動產生的「再接再厲」格數`。
- 有獎數量超過總格數時禁止儲存。
- 未中獎顯示粉紅緞帶「再接再厲」印章，並使用和中獎不同的音效。
- 氣球戳破、金蛋敲裂、中獎、未中獎四種聲音分開。
- 可設定每位玩家限抽一次；重新整理後同瀏覽器仍不能再抽。
- 玩家抽獎結果與主控完整盤面即時同步。
- 中獎格放大顯示獎品名稱與玩家遊戲名。
- 主控可開啟「清剩餘格」模式；主控開出的格子紀錄玩家名保持空白。
- 主控可複製玩家網址、分享文字、抽獎名單、整盤抽獎畫面。
- 玩家頁也有「複製整盤抽獎畫面」按鈕。
- 主控頁、登入頁、玩家頁使用夢幻淡粉／淡紫／淡藍背景。

## 抽獎紀錄格式
玩家正常抽：`第X格 > 獎品 > 玩家名`

主控清剩餘格：`第X格 > 獎品 > `

## 注意
目前房間資料保存在伺服器記憶體中；重新啟動 Node/Render 服務後，舊抽獎房號會失效。


## V1.1.1
- 玩家盤面可自行切換每排 5／7／10 格；設定只影響自己的畫面並記住上次選擇。
- 主控盤也可自行切換每排 5／7／10 格。
- 玩家抽獎結果改為置中大彈窗：中獎顯示獎品大字；未中獎顯示粉紅「再接再厲」印章；兩者音效仍不同。
- 玩家盤面已抽格改為簡潔「✓ 已抽」，不再把獎品與玩家名擠在小格裡。
- 玩家複製整盤圖片會依自己選擇的 5／7／10 格排列，已抽格顯示乾淨的「✓ 已抽」狀態。


## V1.1.2
- 盤面每排顯示數量改為只由主控設定，預設每排 5 格，可選 5／7／10 格。
- 玩家頁移除盤面大小選擇，所有玩家統一依主控儲存的盤面設定顯示。
- 玩家複製整盤圖片也依主控設定的 5／7／10 格排列。
- 手機 5 格模式再縮小圖片與間距，避免窄螢幕擠壓。


## V1.1.3
- 玩家與主控盤面移除 5／7／10 格模式下的白色卡片框、陰影與長方形背景，只保留氣球／金蛋本體。
- 7 格與 10 格模式同步縮短格子高度、間距與圖案尺寸，手機畫面更緊湊。
- 已抽格仍保留淡化／已抽標記；中獎與未中獎結果仍以跳窗顯示。


## V1.1.4
- 修正手機 7/10 格模式雖然圖案變小，但舊 object-card 最小高度仍造成上下大空白。
- 玩家盤面大白底改為近透明淡底。
- 5/7/10 格都重新調整圖案大小、列高與間距；10 格模式圖案稍微放大並緊密排列。
- 主控盤 7/10 格同步清除多餘固定高度。


## V1.1.5
- 主控盤面每排選項改為 5／7／8 格，移除手機效果不佳的 10 格。
- 預設仍為每排 5 格，玩家頁不提供自行縮放，統一跟隨主控設定。
- 氣球飄動效果仍由主控勾選開／關，所有玩家同步；未開啟時氣球固定不動。
- 8 格手機模式重新調整圖案大小、列高與間距，避免圖案過小。


## V1.1.6 預定開賽日期＋時間
- 主控新增「使用預定開賽時間」選用開關；不勾選時維持原本直接開放抽獎。
- 勾選後需設定開賽日期與時間；玩家提早進入會看到「尚未開放抽獎」、開賽時間與即時倒數。
- 玩家可以先輸入遊戲名進入等待，倒數歸零後盤面會自動開放，不必重新整理。
- 伺服器端也會阻止預定時間之前抽獎，避免只靠前端倒數被繞過。
- 若設定的開賽時間已經過去，會直接視為已開放，不會卡住。
- 複製分享文字會自動帶上開賽日期與時間。
